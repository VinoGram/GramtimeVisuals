## 🎨 Design System

### Colors
- Primary: Gray-900 (#111827)
- Background: White (#FFFFFF)
- Secondary: Gray-50 (#F9FAFB)
- Text: Gray-600 (#4B5563)
- Accent: Gray-800 (#1F2937)

### Typography
- Font: System font stack
- Weights: Light (300), Regular (400)
- Tracking: Wide letter spacing
- Sizes: Responsive scale

### Spacing
- Sections: py-24 (96px)
- Components: p-8 (32px)
- Grid gaps: gap-8 (32px)
- Consistent padding/margins

### Components
- Buttons: Outlined & filled variants
- Cards: White with hover shadows
- Modals: Full-screen overlays
- Forms: Clean, minimal inputs
- Icons: Emoji-based (can replace)

## 📊 User Flows

### Booking Flow
```
Services Page → Click "BOOK NOW" → 
Step 1 (Details) → Step 2 (Terms) → 
Step 3 (Review) → Confirm → 
Download Agreement + Email Sent → Success
```

### Gallery Access Flow
```
Client Gallery → Enter Credentials → 
View Gallery Grid → Click Image → 
Lightbox View → Download or Close → 
Logout
```

### Experience Journey
```
Homepage → Scroll Hero → 
Read Brand Story → 
View 8-Step Process → 
Watch BTS Videos → 
Read Philosophy → 
Click CTA → Navigate to Booking/Portfolio
```
