# Intro Screen Images

Place your 7 parallax layer images here. Rename them exactly as listed below.

| Filename       | Layer        | Description                                                                 |
|----------------|--------------|-----------------------------------------------------------------------------|
| `sky.jpg`      | Background   | Wide sky / atmospheric backdrop — fills the entire screen behind everything |
| `four.png`     | Mid-back     | Secondary background element (PNG with transparency) — blends in screen mode |
| `bazaar.png`   | Mid-front    | Main foreground scene (PNG with transparency) — sits above the sky          |
| `split-l.png`  | Split left   | Left half of a split/reveal frame (PNG with transparency)                   |
| `split-r.png`  | Split right  | Right half of a split/reveal frame (PNG with transparency)                  |
| `bridge.png`   | Bridge       | Central hero image that zooms and shifts during scroll (PNG with transparency) |
| `frame2.png`   | Frame 2      | Overlay frame that fades in during the mid-scroll sequence (PNG with transparency) |

## Tips
- `sky.jpg` can be a plain JPEG — it covers the full background
- All other layers should be **PNG with a transparent background** so they composite correctly
- Recommended width: 2400px+ for sharp display on large screens
- Keep file sizes reasonable — compress PNGs with tools like TinyPNG
