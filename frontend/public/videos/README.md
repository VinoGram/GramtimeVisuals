# Videos Folder

Drop your video file here and name it:

  experience.mp4

Recommended specs:
- Format : MP4 (H.264)
- Resolution : 1920×1080 or higher
- Duration : 10–60 seconds (loopable works best)
- File size : keep under 30 MB for fast loading

The scroll-trigger will scrub through the video as the user scrolls.
